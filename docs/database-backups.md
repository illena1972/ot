# Резервное копирование баз данных

Команда `python manage.py backup_databases` создает сжатые копии центральной
базы организаций и всех зарегистрированных рабочих баз MySQL или SQLite.
Копируются в том числе базы неактивных организаций. Для работающей SQLite
используется встроенный Backup API, поэтому копия остается согласованной без
остановки приложения.

По умолчанию файлы сохраняются в `backups/databases/YYYY-MM-DD`, а копии старше
31 дня удаляются только после успешного завершения нового резервирования. Для
каждого запуска создается JSON-манифест с размером и SHA-256 каждой копии.

## Проверка вручную

На хостинге:

```bash
bash deployment/server/backup.sh
```

В локальной установке Windows:

```powershell
powershell -ExecutionPolicy Bypass -File deployment/local/backup.ps1
```

После выполнения проверить наличие файлов `.sql.gz` для MySQL или `.sqlite3.gz`
для SQLite и манифеста в каталоге с текущей датой. Не реже одного раза в квартал
следует проверять восстановление копии в отдельную тестовую базу.

Проверить целостность сжатого файла без восстановления можно командой:

```bash
gzip -t backups/databases/YYYY-MM-DD/*.sql.gz
```

Для контрольного восстановления создать отдельную пустую тестовую базу и
выполнить:

```bash
gzip -dc backups/databases/YYYY-MM-DD/ИМЯ_ФАЙЛА.sql.gz | mysql -h localhost -u ТЕСТОВЫЙ_ПОЛЬЗОВАТЕЛЬ -p ТЕСТОВАЯ_БАЗА
```

Никогда не проверять восстановление поверх рабочей базы клиента.

## Beget CronTab

Создать ежедневное задание типа «Bash-скрипт» на 02:30 и указать:

```text
app.bioclean.ru/deployment/server/backup.sh
```

Включить уведомление по электронной почте об ошибках выполнения.

Серверный скрипт не выводит текст при успешном выполнении, поэтому CronTab не
отправляет ежедневное письмо. Полный результат каждого запуска сохраняется в
`backups/database-logs/backup.log`. При ошибке текст выводится в CronTab и
отправляется на настроенный адрес электронной почты.

## Планировщик Windows

Создать ежедневную задачу от учетной записи, имеющей доступ к каталогу
приложения. В качестве программы указать `powershell.exe`, аргументы:

```text
-NoProfile -ExecutionPolicy Bypass -File "F:\app\ot\deployment\local\backup.ps1"
```

Путь к локальному приложению необходимо заменить на фактический.

## Настройки

- `BIOCLEAN_BACKUP_DIR` задает другой каталог хранения.
- `BIOCLEAN_BACKUP_RETENTION_DAYS` задает срок хранения, по умолчанию 31 день.
- `BIOCLEAN_MYSQLDUMP_PATH` задает полный путь к `mysqldump`, если программа не
  находится через системную переменную `PATH`.

Копии на диске приложения защищают от ошибочного изменения данных, но не от
потери всего аккаунта хостинга. Дополнительно следует хранить хотя бы одну
регулярно обновляемую копию вне Beget.
