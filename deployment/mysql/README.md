# Локальная база MySQL

Для локальной установки создаётся отдельная база `bioclean_local` и отдельный
пользователь `bioclean_app`. Программа не должна подключаться к MySQL от имени
`root` или другого администратора.

1. Откройте MySQL Workbench и подключитесь как администратор MySQL.
2. Откройте `create_local_database.sql`.
3. Замените `REPLACE_WITH_A_LONG_RANDOM_PASSWORD` на новый пароль длиной не
   менее 20 символов.
4. Выполните скрипт один раз.
5. Сохраните пароль в закрытом месте. Не добавляйте его в Git, документы или
   переписку.

После этого параметры подключения передаются приложению через приватный файл
`.env` или через переменные окружения. Пример переменных находится в
`../mysql.env.example`.
